使用帮助

整理自己的媒体，在可信设备间连接和同步。

开始使用

  1. 打开应用，新建资料库或打开已有资料库。
  2. 通过添加菜单选择照片或文件；Mac 可按导入选项引用或保存原片，iPhone 会保存导入的本机副本。
  3. 播放媒体，使用片段、标签、备注与收藏集整理内容。

资料库密码、设备配对及 App Store 购买分别管理。不要将配对码或资料库密码当成购买凭证。

连接 Mac 与 iPhone

  1. 启动兼容版本的 Mac 应用，让两台设备连接同一可信局域网，并允许系统本地网络权限。
  2. 在 Mac 的“设备与连接”打开供其他设备连接的入口；在 iPhone 选择发现的 Mac，或输入 Mac 显示的地址。
  3. 用 Mac 显示的配对码建立信任，再选择资料库。配对后可使用可用的网络线路；远程访问仍需你在两端配置 Tailscale 等可互通网络。
  4. 使用远端原片时，Mac 应用及原片所在磁盘需保持可用。

连接或播放失败

  • 找不到设备：检查两端网络、本地网络权限，以及路由器是否隔离设备；再尝试 Mac 显示的手动地址。
  • 设备离线：确认 Mac 应用正在运行、电脑未休眠，原片磁盘已接入。远程连接还需检查 Tailscale 登录、连接及访问规则。
  • 媒体不能播放：先检查原片是否可用。有些格式需要 Mac 准备兼容播放副本，首次生成需要等待；并非所有格式都能由 iPhone 独立解码。
  • iCloud 导入等待：确认系统能下载所选项目，网络恢复后重试。
  • 生物识别不可用：使用资料库密码解锁；不要删除唯一资料副本来尝试解决。

离线与空间管理

出门前下载所需媒体或启用收藏集离线，并核对任务已完成。离线整理的变更会在恢复连接后同步；iPhone 后台运行仍受系统限制。蜂窝网络播放和传输可能产生流量费用。

清除可重建缓存不会删除托管原片。移除资料库或本机文件前，先检查未同步变更、唯一副本和任务提示，必要时先完成备份。

购买帮助

在提供 App 内购买的版本中，使用应用内的“恢复购买”恢复同一 App Store 购买账户的有效权益。自动续期订阅可在 Apple 的订阅设置中管理；购买买断不会自动取消原有订阅。商品未显示时先检查网络及 App Store 登录状态，再稍后重试。

Support

Organize your own media and connect devices you trust.

Get started

  1. Open the app and create a library, or open an existing one.
  2. Use the add menu to select photos or files. Mac import options can reference or save originals; iPhone imports save local copies.
  3. Play your media and organize it with clips, tags, notes, and collections.

Library passwords, device pairing, and App Store purchases are managed separately. A pairing code or library password is not proof of purchase.

Connect Mac and iPhone

  1. Run a compatible Mac version, join the same trusted local network, and allow local network access in system settings.
  2. On Mac, open the option for other devices to connect in Devices and Connections. On iPhone, choose the discovered Mac or enter the address it displays.
  3. Use the Mac's pairing code to establish trust, then select a library. After pairing, available routes can be used; remote access still requires a reachable network you configure on both devices, such as Tailscale.
  4. For remote originals, keep the Mac app and the disk containing the originals available.

Connection and playback issues

  • Device not found: Check networks, local network permission, and router device isolation. Try the manual address displayed by the Mac.
  • Device offline: Keep the Mac app running, the computer awake, and the original disk connected. For remote access, check Tailscale login, connection, and access rules.
  • Media will not play: Check that the original is available. Some formats require a compatible playback copy prepared by Mac, which takes time initially. iPhone cannot independently decode every format.
  • iCloud import waiting: Check that the system can download the selected items, then retry when connected.
  • Biometric unlock unavailable: Use the library password. Do not delete your only copy of a library to troubleshoot.

Offline use and storage

Before leaving, download the media you need or enable offline collections, and verify completion. Offline edits sync after reconnecting. iPhone background activity is limited by the operating system. Cellular playback and transfers may incur data charges.

Clearing regenerable caches does not delete managed originals. Before removing a library or local files, check unsynced changes, unique copies, and active tasks, and make a backup when needed.

Purchase help

In versions offering in-app purchases, use Restore Purchases to restore valid access belonging to the same App Store purchasing account. Manage auto-renewing subscriptions through Apple. A lifetime purchase does not automatically cancel an existing subscription. If products do not load, check your connection and App Store sign-in, then retry later.
